ATTENDANCE MANAGER 2.0 — INSTALLABLE APP EDITION

Included: index.html, manifest.webmanifest, sw.js, icon.svg.

HOW TO USE
- For a quick preview, open index.html in a modern browser.
- For installation as an app with offline shell caching, host this folder on an HTTPS static host (for example GitHub Pages or Netlify).
- Open the HTTPS URL in Chrome on Android and choose Install app / Add to Home Screen. On iPhone, open in Safari, tap Share, then Add to Home Screen.
- After the first successful online load, the app shell is cached for offline reopening.

FEATURES
- Light and dark themes.
- Student profile and configurable attendance target.
- Subjects, Present / Absent / Leave records, class-type prompt.
- Monthly calendar with attendance-day colours and daily details.
- Weekly timetable planner.
- Attendance insights and subject comparison.
- Calculates consecutive classes to attend to reach target (assumes all upcoming classes are attended).
- JSON backup/restore, CSV export, subject rename/delete.
- Local browser storage; no account or backend required.

LIMITATIONS
- This is an installable Progressive Web App (PWA), not a signed APK/Play Store package.
- Attendance records are local to the browser/device. No cloud sync, Google sign-in, owner approvals, or remote admin panel.
- Browser storage can be cleared; download backups regularly.
- Service worker/offline app-shell installation requires HTTPS hosting (or localhost); opening the HTML file directly is preview-only.
